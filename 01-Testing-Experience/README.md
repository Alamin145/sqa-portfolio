## Testing Responsibilities

### Requirement Analysis

* Analyze client and business requirements.
* Identify functional and business rules.
* Clarify ambiguous requirements before development/testing.
* Validate system functionality against requirements.
* Prepare requirement-based testing scenarios.

### Test Scenario & Test Case Design

* Create positive and negative test scenarios.
* Prepare detailed test cases based on business requirements.
* Cover functional, boundary, validation, integration, and workflow scenarios.
* Maintain reusable testing documentation.

### Functional Testing

* Verify individual features and modules.
* Validate input fields, calculations, workflows, permissions, and validations.
* Test different user roles and access levels.
* Verify expected vs. actual results.

### Regression Testing

* Retest fixed issues.
* Verify that new changes do not break existing functionality.
* Perform regression testing before production release.

### Bug Reporting & Verification

* Identify and reproduce software defects.
* Document bugs with clear steps to reproduce.
* Provide expected and actual results.
* Verify fixes after development changes.
* Perform retesting and regression testing.

### UAT & Client Support

* Support clients during User Acceptance Testing.
* Validate real-world business workflows.
* Analyze client-reported issues.
* Coordinate with development teams for issue resolution.
* Support production deployment and post-release validation.
